# Milestone v1.0 — Stable Release

## Goal

Repo Lens を継続利用できる安定版へ引き上げる。新機能追加よりも、安定性、互換性、性能、ドキュメント、配布品質を優先する。

Marketplace 公開は必須ではなく、v1.0 の完成時点で公開可否を判断する。

## Deliverables

### Compatibility

- 対応 IntelliJ IDEA build 範囲を確定する
- 対象 build で Plugin Verifier を実行する
- deprecated API を棚卸しする
- Public API を優先する
- 対応 IDE / language 条件を文書化する

### Stability

- 一つの Analyzer の失敗で全解析が停止しない
- Cancellation が主要 Scope で機能する
- Indexing / Dumb Mode を安全に扱う
- File change / rename 後の stale Finding を適切に扱う
- ソースコード本文を通常ログへ出力しない

### Performance

小・中・大規模 project で以下を確認する。

- Tool Window 初期化
- Project analysis
- Local Changes analysis
- Branch Diff analysis
- UAST analysis
- dependency analysis
- Git history / Hotspot
- memory usage
- cancellation latency

通常の編集操作を著しく阻害しないことを release gate とする。

### UX polish

- Empty state
- Analysis progress
- Partial result
- Error / skipped analyzer explanation
- Keyboard navigation
- Copy feedback
- Settings descriptions
- Ignore / suppress management
- Provider capability view

### Documentation

- README
- Installation
- Quick start
- Supported IDE / languages
- Checks reference
- Scope reference
- Copy for AI format
- Settings
- Ignore / suppress
- Privacy 方針
- Known limitations
- Troubleshooting
- Development / build instructions
- Architecture overview
- Milestones / changelog

### Distribution

- Plugin name / ID / package の最終確認
- icon / description
- versioning policy
- changelog
- 再現可能な plugin artifact build
- Marketplace 公開可否の判断

## Quality gates

- Unit tests
- Fixture tests
- Integration tests
- Regression tests
- Plugin Verifier
- Real repository smoke tests
- Plugin artifact install test

v0.1〜v0.4 の Acceptance Criteria を regression checklist として再確認する。

## Acceptance Criteria

- [ ] 対応 IntelliJ IDEA build 範囲が明文化されている
- [ ] Plugin Verifier に重大な互換性エラーがない
- [ ] Analyzer failure isolation が機能する
- [ ] Project / Local Changes / Branch Diff で Cancellation が機能する
- [ ] Indexing 中の状態表示と制限が安定している
- [ ] 実 Repository で編集操作を著しく阻害しない
- [ ] v0.1〜v0.4 の主要機能に重大な regression がない
- [ ] Copy for AI の出力仕様が文書化されている
- [ ] 対応言語と capability が文書化されている
- [ ] Privacy 方針が文書化されている
- [ ] ソースコードを自動で外部送信しない
- [ ] API key や有料外部サービスを必須としない
- [ ] README / Quick start / Troubleshooting が整備されている
- [ ] install 可能な plugin artifact を再現可能に生成できる
- [ ] Known limitations が整理されている
- [ ] Marketplace 公開可否の判断が記録されている

## Marketplace decision

公開する場合は、一般ユーザーにも価値があり、対応環境と制限が明確で、継続メンテナンス可能であることを条件とする。

個人 workflow への依存が強い、対応環境の制約が大きい、メンテナンス負荷が価値に見合わない場合は private / local 利用を継続する。公開しない判断でも v1.0 の完成を妨げない。

## Post-v1.0

追加 Language Provider、新しい metric、Export format 追加などは、v1.0 完了後に実需要が確認できた場合のみ検討する。
